Backup Clinica

Ferramenta de uso pessoal de Ivo para guardar cópias criptografadas do banco do projeto Clínica. A automação está em configuração e ainda não está ativa.

O fluxo planejado exporta o banco autorizado, criptografa o arquivo e envia a cópia ao Google Drive da conta que concedeu autorização. A autorização inicial é feita pelo próprio titular. A execução programada será configurada no GitHub Actions.

O acesso ao Google Drive destina-se somente aos arquivos criados ou explicitamente autorizados para esta ferramenta, usando a permissão drive.file. Não há finalidade de consultar e-mails, contatos ou outros documentos da conta.

Os backups não são disponibilizados ao público. A publicação desta página não libera o sistema clínico para uso com dados reais.
