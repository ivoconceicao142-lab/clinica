Política de privacidade — Backup Clinica

Atualizada em 16/11/2026.

Responsável: Ivo. Contato: fcsistema.backup@gmail.com.

Finalidade e situação atual

Backup Clinica é uma ferramenta pessoal para cópias criptografadas do banco autorizado do projeto Clínica. A automação está em configuração. Esta política descreve o tratamento previsto para sua ativação.

Acesso ao Google Drive

A ferramenta solicitará a permissão drive.file, limitada aos arquivos criados ou explicitamente autorizados para ela. Usará identificadores, nomes, tamanhos e informações necessárias para enviar e conferir os arquivos de backup. Não solicitará acesso ao Gmail ou aos contatos.

Processamento e armazenamento

O fluxo previsto exporta dados do Neon em um executor do GitHub Actions, criptografa o backup antes do envio e armazena o arquivo criptografado no Drive autorizado. O executor processará temporariamente a exportação sem criptografia durante a execução. Credenciais de conexão, autorização e criptografia deverão ser guardadas nos segredos da configuração, nunca no código público ou nos registros de execução.

Neon, GitHub e Google participam do processamento conforme suas respectivas funções. Os dados não serão vendidos, usados para publicidade ou treinamento de modelos, nem compartilhados para finalidades alheias ao backup.

Retenção e controle

As cópias permanecerão no Drive até exclusão pelo titular. Não há exclusão automática configurada. A senha de recuperação deve ser guardada separadamente; perdê-la pode impedir a recuperação do arquivo.

O titular pode revogar o acesso nas configurações de conexões da Conta Google e desativar o fluxo no GitHub. Revogar a autorização impede novos acessos, mas não exclui cópias já existentes. Para removê-las, exclua os arquivos e esvazie a lixeira do Drive, observando também eventuais cópias locais.

Uso de dados Google

O uso de informações recebidas das APIs Google seguirá a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
